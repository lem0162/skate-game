SKATE Icon Generator

Renders icon.svg into the PNG sizes a PWA needs. Click each download button (or "Download All") and save them into the icons/ folder.

What to do with the files:
Save each PNG into skate-app/icons/ using the exact filename shown above each preview. The three required files are:
  • icons/icon-192.png — Android home-screen icon
  • icons/icon-512.png — Android splash & larger surfaces
  • icons/apple-touch-icon.png — iOS home-screen icon (180×180)
